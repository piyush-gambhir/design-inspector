# Font fixture: Inspector Test Sans

`inspector-test-sans.woff2` (912 bytes) is not a third-party font. It is original work,
generated by `make-fixture-font.py` in this directory, and it exists only so the
font-identity end-to-end test has a real WOFF2 to serve: a file Chrome will load and paint
with, whose `name` table the parser in `lib/readings/font-file.ts` can read, and whose
advance widths are far enough from any system font that the canvas rendering check can tell
it apart from its fallbacks.

Copyright 2026 Piyush Gambhir, with Reserved Font Name "Inspector Test Sans".

Licensed under the SIL Open Font License, Version 1.1. The canonical text of that licence
is published at <https://openfontlicense.org>; the font's own `name` table carries the same
statement in ids 13 and 14, which is what the test reads back.

The glyphs are plain rectangles. It is a legible file, not a legible typeface, and it is
not intended for any use outside this test suite.

## Regenerating

```bash
python3 e2e/fixtures/fonts/make-fixture-font.py
```

Requires `fontTools` and the Python `brotli` module. Neither is a project dependency: the
committed `.woff2` is what the test suite uses, and the script is here so the binary has a
provenance rather than being an opaque blob.
